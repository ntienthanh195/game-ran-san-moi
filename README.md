# 🐍 Game Rắn Săn Mồi (Snake Game C++)

Chào mừng đến với dự án game đầu tay của **Nguyễn Tiến Thành** (@ntienthanh195)! 
Đây là phiên bản tái hiện tựa game Rắn Săn Mồi huyền thoại trên nền tảng Console, được tối ưu hóa bằng C++.

![C++](https://img.shields.io/badge/Language-C++-blue) ![Status](https://img.shields.io/badge/Status-Completed-green)

## 🎮 Cách chơi (Controls)
Sử dụng các phím điều hướng để điều khiển chú rắn săn mồi:
* **W**: Đi lên ⬆️
* **S**: Đi xuống ⬇️
* **A**: Sang trái ⬅️
* **D**: Sang phải ➡️

## ✨ Tính năng nổi bật (Update C6)
* ✅ **Core Game:** Đã đổi tên chuẩn thành `SNAKE.cpp` và `SNAKE.h`.
* ✅ **Tối ưu:** Di chuyển mượt mà, xử lý giật/lag.
* ✅ **Giao diện:** Menu khởi động đơn giản, hiển thị điểm số thời gian thực.
